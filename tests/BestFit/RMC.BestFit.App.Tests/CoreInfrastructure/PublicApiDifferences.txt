# XGoodFit's App API (RMC.BestFit.App, the XGoodFit assembly) against RMC-BestFit's: the reviewed differences.
#
# PublicApiCompatibilityTests checks that every line of upstream's API baseline
# (upstream/RMC-BestFit/src/RMC.BestFit.App.Tests/CoreInfrastructure/PublicApiBaseline.txt) has its counterpart in the
# port's API, in the same type, after the type maps (MAP) and the rewrites (LINE, RULE) below, unless it is a reviewed
# difference (DIFF). Each entry must still be needed: one that matches nothing upstream lost fails the test too.
# PortPublicApiBaseline.txt is the port's own API, which PublicApi_MatchesCapturedBaseline pins.
#
# Entries, one per line, fields separated by " | " (a "*" type is any type):
#   MAP  | <WPF type>                | <the port's type>                    | <reason>
#   LINE | <type> | <upstream line, mapped> | <the port's line>             | <reason>
#   RULE | DependencyProperty                                               | <reason>
#   DIFF | <type> | <upstream line, mapped>                                 | <reason>

# Type maps: WPF's types in upstream's API, and their counterparts in the port's.
MAP | System.Windows.Application | Avalonia.Application | The application class is an Avalonia application.
MAP | System.Windows.Controls.UserControl | Avalonia.Controls.UserControl | The views and properties panels are Avalonia user controls.
MAP | System.Windows.Controls.Control | Avalonia.Controls.Control | Controls are Avalonia's (MainProjectNode's GetDocumentControl and GetPropertiesControl).
MAP | System.Windows.UIElement | Avalonia.Controls.Control | FrameworkUI's port takes Avalonia controls where WPF-Framework took UIElements (MainProjectNode's GetPropertiesControl, GetControlElement, PropertiesClosed and DocumentClosed overrides).
MAP | System.Windows.Media.ImageSource | Avalonia.Media.IImage | Images are Avalonia's (BatchRunItemViewModel's ElementImage, the batch run list's element icons).
MAP | System.Windows.Data.IValueConverter | Avalonia.Data.Converters.IValueConverter | The value converters are Avalonia's (BatchRunStatusToIconConverter).
MAP | System.Windows.IInputElement | Avalonia.Input.IInputElement | The controls' input element interface is Avalonia's.
MAP | System.Windows.Markup.IHaveResources | Avalonia.Controls.IResourceHost | A control's or the application's own resources are Avalonia's resource host.

# Rewrites: members whose WPF form has an Avalonia form.
RULE | DependencyProperty | A dependency property is an Avalonia styled property: upstream's FIELD public System.Windows.DependencyProperty XProperty is FIELD public Avalonia.StyledProperty<T> XProperty, where T is the type of the class's property X (which is unchanged).
LINE | * | METHOD public sealed-virtual System.Void InitializeComponent() | METHOD public System.Void InitializeComponent(System.Boolean optional=true) | A XAML class's generated InitializeComponent: WPF's implements IComponentConnector; Avalonia's takes an optional loadXaml argument, so calls to InitializeComponent() compile unchanged.
