Select By Attribute

The Select By Attribute Window is used to select rows from the attribute table based on specific search criteria.



Available Fields



The Available Fields is a list of the column names (attributes) for the selected file. The picture above is of a structure inventory. Double clicking these names will place them in the calculation area in the proper format. Field names must have square brackets around them.

Functions



The Functions section lists the available functions that can be used to manipulate data. Functions can be selected by clicking the arrow to the left of the catagory name, then double clicking on the function name. The function will appear in the calculations area. There are buttons of commonly used math functions that can be clicked to add them to the calculations area. All of the math functions and math operators can simply be typed into the calculations area. Help documents exist for the individual functions. Right click on the name of the desired function and left click on the help document.

Calculations Area



The Calculations Area is where the equations are created to select the desired rows. If your equation has errors, the ErrorLog button is enabled. Click the botton to receive the error messages. When no errors exist, the Execute botton will be enabled and the value of the first row will be displayed in the bottom left corner.
